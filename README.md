# dom-v-sochi.ru
Современный дом в Сочи в микрорайоне Сергей-Поле. 131 м² жилой площади, 3 спальни, 2 санузла, участок 3 сотки и терраса на крыше. Панорамный вид на горы, мебель и техника остаются. До моря 15 минут, до центра Сочи 15–20 минут. Продажа без комиссии.
